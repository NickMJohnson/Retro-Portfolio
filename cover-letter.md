# Cover Letter Template

Reusable template. Bracketed `[…]` sections are the only parts that should change per application.

## Usage notes

- **The third sentence of paragraph one is the only paragraph that has to be custom.** Recruiters can tell instantly when it's missing. If you can't write it specifically, the company isn't worth applying to that day.
- **Pick one project to lead with**, not all three. The template shows Clairvoyant first because it's most recent and most generally relevant; if you're applying to an embedded role, lead with Rocketry instead.
- **Drop the founder paragraph** for big-company / IC roles where it might read as flight-risk. Keep it for startups, founding-engineer roles, and any company that explicitly values ownership.
- **Length:** this lands around 350 words, which is right. Resist adding more.

Three things from my background that map to what you're building:

**Shipping under real constraints.** On Cornell Rocketry's Recovery & Payload team I wrote autopilot flight software that fused GPS, altimeter, compass, and accelerometer data to steer our payload back to a predefined landing zone after launch. Embedded systems don't forgive sloppy code — every bug shows up at Mach 1 — and that's where I learned to think about failure modes before writing the happy path.

**Full-stack AI, not just demos.** My current project, **Clairvoyant Crime Search**, is a natural-language video search engine for surveillance footage: investigators type "person with a yellow backpack" and we surface ranked clips across all cameras with per-query bounding boxes. I built it on FastAPI + PostgreSQL/pgvector + OpenCLIP with a React/TypeScript frontend, all containerized. Earlier, **SolidGuard** (built for Cornell's Explorations in ML course) flagged Solidity smart-contract vulnerabilities using a reproducible RAG pipeline over paired safe/malicious contracts and Slither static analysis. **[Swap in whichever project is closest to the role — Clairvoyant for AI/CV, SolidGuard for ML/security, Rocketry for embedded/systems.]**

**Owning things end to end.** I've started three companies — LifeTote (a convertible bag/bulletproof vest, scaled to $50k revenue and a patent), Infrared Air (drone-based thermal inspection of 100+ solar arrays), and Versa Finance (a behavioral-psychology personal-finance app with a 12-person team). Founding things teaches you to scope hard, talk to users, and ship the version that actually exists rather than the one you wish existed.
